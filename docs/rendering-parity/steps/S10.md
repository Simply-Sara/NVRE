|---|---|---|---|---|

| S10-6 | The camera's input mapping matches GECK's — right-drag turns, middle-drag slides, wheel walks — and none of them pivots | `motion_for`/`motion_held` unit tests over button sequences | O2 | implemented, untested |

**S10-5 is a real gap, not a nicety.** Skyrim and Fallout both ship a
multisample setting, and an alpha-tested edge that is hard in the editor and
soft in the game is exactly the kind of mismatch that reads as "the pipeline
does not match" even when every discrete stage is correct.
