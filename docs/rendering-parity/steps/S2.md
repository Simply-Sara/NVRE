# S2 — Scene graph

| ID | Step | Check | Oracle | Status |
|---|---|---|---|---|
| S2-1 | Every shape is reachable from exactly one root, and no node has two parents in the resolved graph | corpus walk over `scene_objects`: count nodes with a parent that is not a node, and shapes with no path to a root | O4 | to write |
| S2-2 | The root's transform is applied exactly once | `model.rs` takes `out.root` from the parentless object and composes it into every shape's world position; unit test a two-level file with a known root transform | O4 | to write |
| S2-3 | A NIF's rotation is row-major and is transposed into Bevy's column-major, and the scale is applied on the correct side of the rotation | `affine()` at `model.rs:391` — unit test with a 90° rotation and a non-uniform scale, against the matrix the game would build | O2 | rule tested informally, no test |
| S2-4 | A node listed as a child by two parents is not silently dropped | corpus count of blocks appearing in more than one `children` list; then decide and document the rule | O4 | to measure |
| S2-5 | The `name` of every node and shape survives the string-table resolution, because `EditorMarker*` detection and skin binding both key off it | corpus count of nodes with a name before and after `resolve_strings` | O4 | to write |

**Note on S2-3.** This is the one place in S2 where a wrong answer looks like a
geometry bug downstream — a model that is correctly shaped but mirrored or
sheared. It is worth a test of its own rather than being folded into S3.
