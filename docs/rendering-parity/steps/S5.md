# S5 — Textures

| ID | Step | Check | Oracle | Status |
|---|---|---|---|---|
| S5-1 | **BC4, BC5 and BC7 are read.** The reader's format table stops at DXT5, so every Fallout 4 normal map (BC5) and most FO4 colour textures (BC7) fail to load | extend `crates/nvre-dds`'s `Format` and `PixelFormat::format`, map to `Bc4RUnorm`/`Bc5RgUnorm`/`Bc7RgbaUnorm(+Srgb)`; unit test the header→format table | O2 | **defect: three formats missing** |
| S5-2 | The DX10-extended header is read, so a DDS whose format is carried by a DXGI number rather than a four-character code works | unit test over a synthesised DX10 header; the BA2 writer already produces them (`ba2::dds_from_texture`), so the corpus exists | O2 | **defect: DX10 header not parsed** |
| S5-3 | The sRGB decision is right per slot: colour textures sRGB, normal maps and glow masks not | unit test on the mapping; corpus count of textures per slot kind | O2 | colour sRGB, normal/glow linear — verify per game |
| S5-4 | Every mip level is uploaded, and the level count the header claims equals the bytes present | `dds_image` already carries all levels; unit test a 3-level DDS | O4 | implemented, untested |
| S5-5 | The sampler is repeat/linear/anisotropic, and the anisotropy follows the game's own `iTexAnisotropy` | `set_anisotropy` exists and **has no caller**; wire it to the setting or delete it | O2 | **defect: dead setting** |
| S5-6 | `get_clamped` — the clamped-edge variant — has a caller, or is deleted | grep: it has none | O4 | **defect: dead code** |
| S5-7 | A texture that fails to load is reported once and counted, not silently skipped per frame | `TextureCache::failures` exists; print the counts per game and per class | O4 | collected, not reported |
| S5-8 | `.bgsm` / `.bgsm`-style material files resolve their diffuse, normal and glow by slot, and the path heuristic (`_n`, `_g`, `_m`) is checked against what the games actually ship | `extract_bgsm_textures` is a string scan over the binary; corpus count of BGSM-referenced shapes and their resolved textures | O2 | heuristic, unverified |

**Why S5-1 is the headline.** Fallout 4 is one of the five games the plan
targets, and its textures are the least verified of the five because the two
formats that carry most of them are not read. That is not a refinement — it is
a hole.
