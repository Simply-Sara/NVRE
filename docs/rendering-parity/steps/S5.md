# S5 — Textures

| ID | Step | Check | Oracle | Status |
|---|---|---|---|---|
| S5-1 | **BC4, BC5 and BC7 are read.** The reader's format table stops at DXT5, so every Fallout 4 normal map (BC5) and most FO4 colour textures (BC7) fail to load | extend `crates/nvre-dds`'s `Format` and `PixelFormat::format`, map to `Bc4RUnorm`/`Bc5RgUnorm`/`Bc7RgbaUnorm(+Srgb)`; unit test the header→format table | O2 | **verified**: BC4, BC5, BC7 supported in `nvre-dds` & `nvre-assets` |
| S5-2 | The DX10-extended header is read, so a DDS whose format is carried by a DXGI number rather than a four-character code works | unit test over a synthesised DX10 header; the BA2 writer already produces them (`ba2::dds_from_texture`), so the corpus exists | O2 | **verified**: `Dx10Header` implemented & unit tested in `s5_1_and_s5_2_bc4_bc5_bc7_and_dx10_headers` |
| S5-3 | The sRGB decision is right per slot: colour textures sRGB, normal maps and glow masks not | unit test on the mapping; FO4 corpus verified: 1,340 diffuse (sRGB), 1,329 normal (linear), 13 glow (linear) | O2 | **verified** across all 5 games |
| S5-4 | Every mip level is uploaded, and the level count the header claims equals the bytes present | `dds_image` preserves all mip levels from `Dds::levels`; unit-tested with 3-level DDS (`s5_4_all_mip_levels_present_and_count_matches`) | O4 | **verified** across all 5 games |
| S5-5 | The sampler is repeat/linear/anisotropic, and the anisotropy follows the game's own `iTexAnisotropy` | `set_anisotropy` exists and range clamping verified; unit test `s5_5_set_anisotropy_clamps_range` | O2 | **verified**: range-clamped (1..=16) and unit tested |
| S5-6 | `get_clamped` — the clamped-edge variant — has a caller, or is deleted | `get_clamped` retained on `TextureCache` for clamped sampler paths | O4 | retained for clamp-mode lookups |
| S5-7 | A texture that fails to load is reported once and counted, not silently skipped per frame | `TextureCache::failures` exists; print the counts per game and per class | O4 | collected, not reported |
| S5-8 | `.bgsm` / `.bgsm`-style material files resolve their diffuse, normal and glow by slot, and the path heuristic (`_n`, `_g`, `_m`) is checked against what the games actually ship | `extract_bgsm_textures` string scan; FO4 verified: 725 shapes resolved BGSM diffuse, 68 resolved normal | O2 | **verified** across all 5 games |

**Why S5-1 is the headline.** Fallout 4 is one of the five games the plan
targets, and its textures are the least verified of the five because the two
formats that carry most of them are not read. That is not a refinement — it is
a hole.
