# S6 — Material build and shader

| ID | Step | Check | Oracle | Status |
|---|---|---|---|---|
| S6-1 | The `NifSurface` `Default` is the neutral surface — `Falloff::NONE` = (1,0,1,1), not `Vec4::ZERO` — so a shape built with a default extension is fully opaque rather than invisible | unit test asserting `NifSurface::default().falloff == Falloff::NONE.params` | O4 | **verified**: asserted in `s6_1_nif_surface_default_is_the_neutral_surface` |
| S6-2 | `material_for` populates every field of the extension on the path that actually spawns meshes — a shader that exists but is never fed is dead code | unit test over a synthetic `ShapeProps` with falloff, cut, add-whole and decal set, asserting all four reach the extension | O4 | **verified**: asserted in `s6_2_material_for_populates_every_extension_field` |
| S6-3 | An unlit shape keeps `unlit: false` on the base material and is gated in the shader, because `StandardMaterial` bypasses extension shaders when `unlit` is set | unit test on `material_for`'s output for an unlit shape | O2 | implemented, not asserted |
| S6-4 | The editor marker's grey shell is a decision, not the file's description — and only a *game* renderer would skip it | unit test on `is_editor_marker`; corpus count of marker shapes per game | O2 | tested |
| S6-5 | Vertex colours are cleaned against the shape's own flags: alpha forced to 1 unless the shader takes it, non-finite clamped to white, and an unlit shape's colour converted display→linear | `fix_vertex_colors` unit test covering each branch; corpus count of shapes whose stored alpha is zero | O4 | implemented, one branch tested |
| S6-6 | A normal map is bound only when the mesh has UVs and tangents could be generated | `model.rs:302` unit test with a UV-less mesh | O4 | gated, not tested |
| S6-7 | The multiply and additive blend equations match the engine's, including the working-space gamma and the alpha power | unit tests on `multiply_factor` and `add_alpha`; the engine's exact constants are residue until a capture settles them | O5 | tested against themselves only |
| S6-8 | A see-through shape takes no shadow, and the marker is removed when the material changes back | `see_through_casts_no_shadow` unit test over the three-state transition | O4 | implemented, not tested |
| S6-9 | `shade_light` — a shape whose sun shadows come from another light's map — has a caller or is deleted | grep: `NifSurface::shade_light` is set to `false` in one place and read by the pipeline; nothing sets it true | O4 | **defect: dead flag** |
| S6-10 | `hard_edges` has a caller or is deleted | grep: same — always `false` | O4 | **defect: dead flag** |

**The pattern to watch for.** S6-1, S6-2, S6-9 and S6-10 are all the same
class: a field that exists, is read by the shader or the pipeline, and is
never written by the code that spawns meshes. That class produced the "every
blended shape invisible" bug and the "every unlit shape drew lit" bug. A test
per field is the only thing that keeps it closed.
