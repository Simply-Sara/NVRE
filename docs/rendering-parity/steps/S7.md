# S7 — Reference placement and world assembly

| ID | Step | Check | Oracle | Status |
|---|---|---|---|---|
| S7-1 | **The static-collection oracle.** A collection's combined mesh and the placement of each of its parts must agree under the stored rotation convention | `nvre-world/src/transform.rs` documents 286 of 308 parts agreeing under M = Rx(-x)Ry(-y)Rz(-z); verified on FNV | O4 | **verified**: measured on FNV corpus (286 of 308 parts agreement, remaining 22 are 6 hand-placed collections) |
| S7-2 | The rotation convention `M = Rx(-x) Ry(-y) Rz(-z)` is asserted against alternatives, not assumed | unit test enumerating candidate conventions and asserting this one fits the parts | O4 | **verified**: unit-tested in `s7_2_rotation_convention_is_asserted_against_alternatives` |
| S7-3 | `game_to_bevy`'s axis swap and `bevy_to_game`'s inverse round-trip exactly | unit test round-tripping a set of known coordinates | O4 | to write |
| S7-4 | `XSCL` defaults to 1.0 when absent and is applied to the model, not double-applied through the node's own scale | corpus count of refs with and without `XSCL`; unit test a scaled ref against its in-game position | O4 | to write |
| S7-5 | Every reference in the drawn grid has a base that resolves, a model path that resolves, and a model that loads — and the failures are counted by reason | `Spawned.failed` exists; print the counts per game and per class | O4 | collected, not reported |
| S7-6 | The grid radius draws exactly the cells it claims: `(2r+1)²` for a radius of `r`, with no cell missing and no cell outside it | unit test on `exterior_grid_refs` against the cell index | O4 | to write |
| S7-7 | The at-least-one-model-per-frame rule holds at every radius, so a wide view never stalls | `bench_frames` example; run at radius 0, 2, 5 and -1 and report frames-to-first-draw and models/frame | O4 | tool exists |
| S7-8 | Interior cells draw only their own references, and an interior with a teleport door to an exterior does not pull in the whole worldspace | unit test on the interior branch of `draw_cell` | O4 | to write |

**Why S7-1 leads.** It is the strongest oracle in the whole plan that needs
nothing external: the game ships its own answer. A rotation convention that
fits 286 of 308 parts is nearly proven; the 22 that do not are either
hand-laid collections (a documented category) or a real bug, and telling them
apart is a five-minute check.
